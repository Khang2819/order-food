# Order Food App 🍔🍟

Dự án ứng dụng đặt món ăn (Order Food) bao gồm backend API và ứng dụng di động Flutter.

## Cấu trúc dự án

```
order food/
├── backend/    # REST API server (Node.js, Express)
└── mobile/     # Ứng dụng di động (Flutter)
```

---

## Hướng dẫn cài đặt & khởi chạy

### 1. Backend (Node.js & Express)

```bash
cd backend
npm install
# Khởi chạy server
node index.js
```

### 2. Mobile (Flutter)

```bash
cd mobile
flutter pub get
# Khởi chạy ứng dụng
flutter run
```
